# G検定Pass プライバシーポリシー

最終更新日: 2026年6月21日

G検定Pass（以下「本アプリ」）は、G検定の学習、広告表示、アプリ内課金、品質改善のために必要な範囲で情報を取り扱います。本ポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

## 1. 本アプリが取り扱う情報

### 1.1 端末内に保存される学習データ

本アプリは、以下の学習データを利用者の端末内に保存します。

- 回答履歴
- 正誤履歴
- 苦手問題の情報
- 分野別の学習進捗
- 連続学習日数
- 文字サイズなどの設定情報

これらの学習データは、問題演習、復習、学習進捗表示、誤答優先学習、連続学習日数の表示のために使用します。現時点で、本アプリ独自のアカウント登録機能やサーバー同期機能はありません。

### 1.2 広告に関する情報

本アプリは広告表示のために Google Mobile Ads SDK（AdMob）を利用する場合があります。広告配信のため、広告ID、端末情報、広告の表示・操作に関する情報などが Google により取り扱われる場合があります。

Google による情報の取り扱いについては、Google のポリシーをご確認ください。

- Google プライバシーポリシー: https://policies.google.com/privacy
- Google 広告に関するポリシー: https://policies.google.com/technologies/ads

### 1.3 アプリ内課金に関する情報

本アプリはアプリ内課金の購入状態を管理するために RevenueCat SDK を利用する場合があります。購入状態の確認、復元、プレミアム機能の有効化のため、購入情報、アプリユーザーID、端末情報などが RevenueCat および Apple により取り扱われる場合があります。

各サービスによる情報の取り扱いについては、以下をご確認ください。

- RevenueCat Privacy Policy: https://www.revenuecat.com/privacy/
- Apple Privacy Policy: https://www.apple.com/legal/privacy/

### 1.4 利用状況の分析に関する情報

本アプリは、機能改善、学習体験の改善、利用状況の把握のため、Firebase Analytics を利用する場合があります。Firebase Analytics では、アプリ起動、学習開始、回答、学習完了、模試開始、模試完了、購入画面表示、購入操作、レビュー依頼候補などのイベント情報、アプリバージョン、OS 種別、端末種別などの技術情報が取り扱われる場合があります。

本アプリは Firebase Analytics の利用にあたり、IDFA を使用しない設定を採用しています。また、Firebase Auth、Firestore、Functions、Storage、Remote Config、Crashlytics は本アプリの機能として利用しません。

本アプリは、問題文、選択肢本文、解説本文、自由入力の本文、氏名、メールアドレス、個別の問題ID、生の決済ID、広告ID、SDKキーを Firebase Analytics のイベントとして送信しません。

Google による情報の取り扱いについては、Google のポリシーをご確認ください。

- Google プライバシーポリシー: https://policies.google.com/privacy
- Firebase におけるデータの取り扱い: https://firebase.google.com/support/privacy

### 1.5 クラッシュ・不具合調査に関する情報

本アプリの安定性向上、不具合調査、品質改善のため、クラッシュ情報、OS バージョン、端末種別、アプリバージョンなどの技術情報が Apple、Expo、または利用している開発基盤により取り扱われる場合があります。

## 2. 利用目的

本アプリは、取り扱う情報を以下の目的で利用します。

- 問題演習、復習、学習進捗表示の提供
- 誤答優先学習、苦手問題モード、連続学習日数表示の提供
- 文字サイズなどの利用者設定の保存
- 広告の表示
- アプリ内課金の購入状態確認、復元、プレミアム機能の提供
- 利用状況の分析、機能改善、学習体験の改善
- クラッシュ、不具合、表示崩れなどの調査と改善
- 不正利用や利用規約違反が疑われる場合の確認

## 3. 第三者提供・外部送信

本アプリは、広告配信、アプリ内課金、品質改善のため、以下の外部サービスを利用する場合があります。各サービスで取り扱われる情報は、それぞれのプライバシーポリシーに従って管理されます。

- Google Mobile Ads SDK（AdMob）
- RevenueCat
- Firebase Analytics
- Apple App Store / StoreKit
- Expo および Apple が提供するクラッシュ・診断関連機能

本アプリの学習履歴は、原則として利用者の端末内に保存されます。ただし、OS、SDK、外部サービスの仕様により、広告、購入、利用状況の分析、クラッシュ、診断に関する情報が各サービスへ送信される場合があります。

## 4. 収集しない情報

本アプリは、以下の情報を本アプリ独自の機能として収集しません。

- 氏名、住所、電話番号
- 連絡先
- 位置情報
- 写真、カメラ、マイクの内容
- 本アプリ独自のログインID、パスワード
- 学習履歴を外部サーバーへ同期するためのアカウント情報
- 問題文、選択肢本文、解説本文、自由入力本文を分析イベントとして送信する機能

## 5. 学習データの削除

利用者は、アプリ内の設定画面から学習データをリセットできます。アプリを削除した場合も、端末内に保存された学習データは削除されます。

なお、Apple、Google、RevenueCat など外部サービス側で管理される購入情報、広告関連情報、クラッシュ情報については、各サービスのポリシーおよび設定に従って管理されます。

## 6. 未成年の利用

本アプリは資格学習を目的としたアプリです。未成年の方が利用する場合は、必要に応じて保護者の方と一緒に内容を確認してください。

## 7. ポリシーの変更

本ポリシーは、法令、外部サービスの仕様変更、アプリ機能の変更に応じて改定される場合があります。重要な変更がある場合は、アプリ内または公開ページ上で分かりやすく告知します。
