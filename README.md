# G検定Pass プライバシーポリシー草案

最終更新日: 2026年6月7日

G検定Pass（以下「本アプリ」）は、学習機能、広告表示、アプリ内課金の提供のために、端末上の学習履歴および外部サービスが提供する識別子等を利用する場合があります。

## 収集する情報

- 学習履歴、正誤履歴、連続学習日数など、アプリ内で保存される学習データ
- 広告配信や課金管理に必要な識別子
- クラッシュや不具合調査に必要な技術情報

## 利用目的

- 問題演習、復習、学習進捗表示の提供
- 広告表示
- アプリ内課金の管理
- 不具合調査と品質改善

## 第三者サービス

本アプリでは、広告配信、課金管理、品質改善のために第三者サービスを利用する場合があります。各サービスで取り扱われる情報は、それぞれのプライバシーポリシーに従って管理されます。
